# StockHunter 台股盤後戰情室

每天自動掃描台股、判斷大盤位階，並透過 Telegram 通知。
全部跑在 GitHub Actions、Render 與 Streamlit 上，不需要自己的電腦開機。

---

## 功能總覽

| 功能 | 說明 | 時間（台灣） |
|---|---|---|
| 盤前晨報 | 國際股市、期貨、VIX、大盤位階（GitHub 08:35 排程；08:40 還沒開始跑由 Render 補叫，GitHub 晚到時已發過就跳過不重發） | 每個交易日 08:35 |

| 盤中殺低後反彈 | 全市場每 90 秒掃一次，殺低 ≥ 4%（5 分鐘內、要出量）後反彈 ≥ 4% 就私訊管理者（Render） | 09:00 ～ 13:30 |
| 恐慌承接預判 | 用盤中數字套恐慌承接規則，推播到群組 | 13:00 |

| 網頁 App | 今日推薦、個股診斷、資金試算（盤後資料 15:30 才更新） | 隨時 |
| Telegram 機器人 | 追蹤清單、查價、即時提醒 | 隨時（Render） |

## 大盤位階（五層）

用加權指數的 MA5、MA10、MA20、MA60 判斷目前在哪一層：

- **第 1 層**：強多頭
- **第 2 層**：多頭
- **第 3 層**：盤整／轉折
- **第 4 層**：空頭
- **第 5 層**：強空頭

每一層啟用的策略不同。第 4、5 層要先通過「止跌確認」才會列出買進名單。

**空頭反彈**（11/14 加入，`LAYER_REBOUND_ON`）：低點日當時是空頭，之後止跌確認通過、而且收盤在 5 日、10 日線上 → 升為第 3 層盤整；再站上月線 → 第 2 層多頭（不用等季線）。當天就換、不等 2 天；跌回 5 日、10 日線下（或跌破低點）就回到原本的判斷。
過熱與恐慌會另外標註，不影響層級。

**止跌確認**（11/14 改版）：「低點日」＝爆量下跌日當天起股價最低的那天（可以就是爆量下跌日；跌破就換成新的低點日、重新計算），兩項都過才算止跌：
① 低點日之後曾經有一天收盤離低點日最低點反彈 ≥ 5%（達成過就算）；② 低點日之後至少 2 個交易日不破低點日最低點（天數沒滿、還沒破低＝觀察中）。
量能（低點日成交額 ÷ 爆量下跌日）和 K 棒下影線只顯示、不卡關。門檻在 `config.py`（`STAB_REBOUND`、`STAB_NO_BREAK_DAYS`）。

## 選股策略

| 策略 | 重點 |
|---|---|
| 低位起漲 | 收盤在十年月線高低的下 20%（低檔），盤整後帶量突破 30 日頸線；突破當天上影線不超過整根 K 棒的 20% |
| 量縮抗跌 | 近 20 日高低差 ≤ 20%（盤整）；近 20 日均量 ≤ 前 60 日的 80%（量縮）；不破前低；所屬族群在大盤不好時排前 5 名（抗跌） |
| 強勢續攻 | 創高拉回、或噴出後整理，再度站上盤整高點 |
| 恐慌承接（觀察） | 先殺後拉、長下影、帶量、振幅夠大；只供追蹤，沒有追價點 |

**大盤不好的定義**：加權指數收盤在 20 日均線之下。量縮抗跌的族群排名，只看最近 20 個交易日內大盤不好的日子。

**族群排名**：用 Yahoo 概念分類頁的成分股，每個族群取中位數的累計跌幅，排前 5 名。每個分類頁只抓得到約 34 檔，所以排名是用部分成分股算的。

分批進場比例可以在網頁 App 調整。

| 檔案 | 用途 |

| `futures_sweep.py` | 台指期「流動性掃蕩」提醒：價格刺破 上個交易日高低、今日全天高低（含昨夜盤）、開盤30分高低後 5 分K 收回，先提醒一次，之後連 2 根 5 分K 沒再創新高（低）再提醒「確認」，又創新高（低）就提醒「失敗」。另外也看「盤中波段高低」（小價位，只看最近 3 小時、離現價 150 點內），提醒標「大價位／小價位」並附成交量倍數（只是參考）。只私訊管理者、不下單；Render 環境變數 `SWEEP_ON=0` 可關閉；`SWEEP_LEVELS=prev_hi=44250,prev_lo=42646` 可手動指定價位（期交所檔案還沒出來時用；舊名稱 day_hi／day_lo／night_hi／night_lo 也認得）；價位以「交易日」整合：一個交易日＝夜盤＋日盤（昨天 15:00 開的夜盤和今天日盤同一天，昨天日盤和前天夜盤同一天），`期貨→行情` 卡片顯示「今日全天」「上個交易日（高低收）」，多空分界用上個交易日整天的 (高+低+收)/3，記在價位存檔的 days 裡；有部位時另外提醒：新的轉折低點（做空＝轉折高點）比目前停損更有利時，問你要不要上移（`FUT_SWING_ALERT_ON`）；價格離前高（做空＝前低）30 點內提醒考慮減碼或停利（`FUT_NEAR_ALERT_ON`、`FUT_NEAR_LEVEL`）；高檔放量滯漲／低檔放量不跌（量 ≥ 20 根均量 2 倍、實體小、收在一側、在本盤高低附近）與結構轉換（轉折高點降低 15 點以上＋5分K 收盤跌破頸線；鏡像＝低點墊高＋站上），高點降低成立、還沒破頸線時先發「👀 留意」不等頸線（`FUT_STRUCT_WATCH`）；日盤收盤後 13:45～13:55 改用期交所官方收盤價（取代最後一筆成交價，有差會私訊一則校正，`FUT_CLOSE_OFFICIAL`），只提醒觀察不下單，自動記進掃蕩紀錄另列一塊（`FUT_PAT_ON`、`FUT_STALL_*`、`FUT_STRUCT_*`）；創新低追空／創新高追多（收盤跌破／站上「全日含夜盤」站穩 30 分鐘以上的低／高點 3 點以上，只記進掃蕩紀錄、不推播，統計另列【創新低追空】【創新高追多】；進場價＝那根收盤，停損遠＝最近 12 根最高（低）、近＝最近 3 根；`FUT_BREAK_ON`、`FUT_BREAK_AGE`、`FUT_BREAK_MIN`、`FUT_BREAK_FAR`、`FUT_BREAK_NEAR`）；創本盤新高／新低提醒（不管有沒有部位：每盤開盤前 30 分鐘只記錄，之後第一次突破馬上提醒，再創高（低）30 點才再提醒，並註明突破了哪些關鍵價位；`FUT_HL_ON`、`FUT_HL_WARM`、`FUT_HL_STEP`）；減少打擾：新轉折低點沒設停損只提醒一次、設了要比上次再有利 100 點（`FUT_SWING_MIN_STEP`）才再提醒；本盤前高（低）靠近同一邊 30 分鐘內不重複（`FUT_NEAR_COOL`）；空手（沒記錄部位）時價格靠近前高或前低 30 點內也提醒「留意建倉機會」，附多空分界與偏多偏空，10 分鐘內最多一則（`FUT_FLAT_NEAR_ON`、`FUT_FLAT_COOL`）。掃蕩紀錄同時記兩種停損（遠＝掃蕩極點、近＝確認那幾根的最低/高點）各自算輸贏；長影線提醒（不需要價位：下/上影線 ≥ 60 點且是最近 20 根平均振幅的 2.5 倍以上、佔整根 K 棒 60% 以上，之後連 2 根沒破影線極點就確認，`FUT_WICK_ON = False` 可關）；config.py 的 `FUT_SWEEP_SWING_ON = False` 可關掉小價位。每次提醒自動記錄（`期貨→掃蕩紀錄` 看統計：確認後 30 分鐘內先走 +80 點算贏、先碰到停損參考算輸，分順勢/逆勢、大/小價位；存在 GitHub 的 `sweep_log.json`，`FUT_LOG_ON = False` 可關；自動統整：每週六 09:00 與確認單每滿 30 筆各推一次，`FUT_LOG_DIGEST = False` 可關；統計改記「碰到停損前先走到幾 R」（追蹤 `FUT_LOG_BARS` 根，預設 24 根＝2 小時）；統計另外分「日盤、夜盤美股開盤前後、夜盤其他」，美股開盤時間夏令冬令自動換算） |

## 需要的 Secrets

在 GitHub 的 **Settings → Secrets and variables → Actions** 設定：

- `TG_BOT_TOKEN`：Telegram 機器人 token
- `TG_OWNER_ID`：管理者的 Telegram 數字 ID（檢查與提醒只私訊這個 ID）
- `TG_CHAT_ID`：群組通知的 chat id
- `FUGLE_API_KEY`：富果行情 API 金鑰

Render 上另外需要 `GH_TOKEN`（備援排程用，期貨部位存檔也用它，要有寫入 repo 內容的權限）與 `FUGLE_API_KEY`。

> 金鑰只放在 Secrets 裡，不要寫進程式碼或 README。

## 已知限制

- GitHub 排程有時會延遲或沒有執行，所以 Render 上有備援排程，沒有跑就補跑一次。
- 證交所與 Yahoo 偶爾連不上時，程式會改用備用來源或顯示警告，結果可能不完整。
- 族群成分股每頁只抓得到約 34 檔（部分名單），族群排名與抗跌判斷會有偏差。
- 量縮抗跌的回測還沒接上族群排名，回測結果目前不含抗跌條件；族群回測也會因為用今天的成分股回看過去，有一點偏差。
- 證交所大盤成交金額約 15:00 才出來，夜間掃描由閘門（`night_gate.py`）等它出現才跑，16:30 還沒出來也會強制掃。
- 盤中殺低後反彈偵測目前只在 11/06 實測過，門檻（殺低 4%、反彈 4%、量能 2 倍、1000 張）還在觀察；Render 重啟後當天的價格紀錄會清空。
- 證交所指數即時資料沒有成交量欄位，無法直接取得大盤估量。
- 期貨風控只記錄你輸入的部位、不會下單；報價來自期交所免費行情，抓不到時會提醒你自己盯盤；部位存檔需要 GH_TOKEN 有寫入權限，否則機器人重啟後部位會不見（會私訊提醒）。
- 策略門檻是依照目前的觀察設定，尚未經過完整回測驗證。
